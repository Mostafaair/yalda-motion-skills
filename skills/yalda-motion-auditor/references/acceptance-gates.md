# Acceptance / stop gates

## Gate -1 — Durable handoff and usage observability (v0.3.0)
- Owner GO and exact isolated workspace; verify historical source hashes and current tool skill activation.
- `progress.json` plus at least one self-contained checkpoint ZIP; SHA verified, Owner-accessible copy explicitly evidenced. If only Work-local files exist, `RECOVERY_UNVERIFIED` / HOLD.
- `work_budget_guard.py` has Owner-approved caps or marks quota/metrics UNKNOWN; measured versus estimated usage separate; no false remaining quota. Do not continue costly work if budget/export gate unresolved.
- Skill Execution Ledger records actual commands and source/build references; attached Skill alone != invocation.

## Gate V — Render-source and visual truth (v0.3.0)
- A/B static edited references or C collage are not accepted as proof of a unified 3D renderer.
- Six native source-generated frames (A1–A3 / C1–C3) must have editable common scene, deterministic render recipe, object/camera data and geometrical continuity. Compare visual quality to R1 and source-model provenance separately.
- Owner must explicitly accept source continuity and visual quality before mass rendering. Missing real SAFE mapping => `CONCEPTUAL/UNVERIFIED`.

## Gate 0 — explicit Owner-defined hard media and caption contract
- User approves global frame count (MAXIMUM or EXACT), global encoded frame MB cap *across all responsive tiers combined*, per-tier optional caps and mandatory scientific checkpoints; no invented caps or fake sign-off.
- Plan and then verify actual manifest: ALL frame files accounted for, count/bytes PASS, no unlisted responsive frames. Separate poster, shell, font, code and non-frame media metrics.
- If no Owner value or constraints conflict with required geometry/quality, HOLD/STOP with alternatives. A lower MB cap is not authorization to simplify approved geometry or fake science.
- Owner-approved bilingual text contract or explicit "no additional text"; test fixed, below-scene, floating and world-anchored overlays as applicable. Structural validator does not replace browser/RTL/accessibility tests.

## Gate A — auditable source and geometry
- Build source and live page alignment demonstrated or `BLOCKED`.
- Approved model geometry, visual checkpoints, scene state inventory.
- Distinguish conceptual vs numerical science; patch IDs and color map available or `BLOCKED`.
- Evidence register initialized with source date/hash.

## Gate B — short proof of continuity and media
- Field→neighbors→total field and patch 3D→plan→SAFE tested in forward AND reverse.
- Same model/camera/p geometry across stages; no obvious double exposure or discontinuity.
- For sequence, bounded decoded cache and priority scheduler described and tested; video tested for random seek and GOP tradeoff; two options compared if feasible.
- Compressed media preserves approved edges, contrast, opening dimensions, and patch colors.

## Gate C — web acceptance
- On staging after separately authorized deployment check module MIME `.mjs` => `text/javascript`, real page Console/Network, 404s, manifest frames/paths, first poster and actual frame changes. Local tests do not establish hosting behavior.
- Cold cache first poster and first interaction benchmark; request count/transfer/decoded working set established.
- Strong input jumps classified: intentional index jumps vs not-ready target vs compositor presentation loss.
- No blank frame or invalid fallback under tested failures; seek backwards reproducible.
- Browser/devices with network conditions reported; actual frame trace/recording, accessibility/reduced motion and mobile assessed.

## Gate C2 — no false evidence
- An analysis of HAR, Chromium Trace or ffprobe metadata is not sufficient to call frame presentation/seek PASS on Safari, Firefox or iOS.
- For a current build, resolve or clearly flag renderer PID ambiguity, unrecognized FrameSequenceTracker format and missing HAR timestamps.
- Synthetic tests validate tool logic only; browser and agent behavioral evaluations remain separately NOT TESTED until evidenced.

## Gate D — Owner decision
- For each criterion `PASS/FAIL/NOT TESTED/BLOCKED` and linked evidence, device and code hash.
- Unresolved P0, unmeasured claim or missing Owner GO => HOLD, not release-ready.
- Delivery report + minimal decision alternatives + STOP.

## Historical project goals, not global standards
2 CSS px landmark tolerance, 60Hz≈16.7 ms render period, and representative viewports are starting design targets only. No fixed global image frame-count limit, no blanket 'X MB acceptable', no global device memory guarantee. Empirical budgets require approved device/network targets and repeated measurements.
